# own-your-health.github.io

The landing page of [Own Your Health](https://own-your-health.github.io/): what the project is, and links to the app and the command-line tools.

- `index.html` and `site.css`: the page. It loads nothing from another site.
- `google568b5a8d990cd811.html`: proves to Google Search Console that this organization owns the site. Keep it; removing it ends the verification.
- `make verify` runs the same check as CI.

GitHub Pages publishes `main` as it is.
